## 怎么使用

### 资料室

进入“资料室”，上方显示当前容量。未被引用的文件可以“移入回收站”；进入回收站后可以恢复，或先点击“彻底删除”、核对文件名后再确认永久删除。只有永久删除才释放容量。显示“引用中，已保护”的文件不能直接删除，避免旧任务和档案打不开。

### 只重新做一个镜头

打开原运营任务 → 视频剪辑 → 对应片段的“替换镜头”。在“生成新的备用镜头”输入新要求，核对时长、比例和清晰度，确认新增生成费用，再点击“只生成这一镜头”。生成结果先保留在待选区；点击预览，满意后确认替换。其他片段和声音字幕不变，可以撤销本次替换。

本功能每次最多生成15秒；短于5秒的剪辑片段会生成至少5秒素材，再按原片段长度截取。模型是否接受具体时长以服务商实际能力为准。结果待核对时不要换编号再次提交；先检查原任务或联系维护人员核对，避免重复计费。

### 配音和字幕

在剪辑设置的“中文配音与自动字幕”输入文案，用句号分句。点击生成试听，本机语音不调用付费模型。试听后点击“采用这份配音”；如需替换旧字幕，明确勾选“同时用配音字幕替换当前字幕”。默认保留旧字幕。

配音必须短于成片，否则给出提示，不截断。每句最多100字，最多30句。可设置0至5秒配乐淡入淡出，并开启“配音期间降低配乐音量”。字幕与声音在完整预览里同步，导出沿用相同设置。该本机配音功能需要Mac已安装中文语音；其他服务器尚未接入语音服务时返回明确不可用提示。

### 版本和定稿

“成果版本”列出独立导出记录。选中后可预览、下载或载入旧设置继续修改；导出会另存新版本。选择“对照版本”可以并排播放两份视频。点击“将本版本标记为定稿”只改变定稿标记，不删除其他版本。归档仍需点击归档按钮。

### 自检和服务恢复

设置里的员工自检保存最近结果，并能展开此前记录。模型配置版本变化后，旧结果显示“配置已变更，请重新自检”。图片和视频仅核对配置，不应把这项自检当作媒体生成成功证明。

Start-Local会启动本地守护，Stop-Local先停守护再停服务。守护每30秒检查主站和原生视频进程，连续失败两次后尝试恢复已退出的服务；同一小时最多5次恢复，不杀死仍存活的进程、不修改模型配置、不重新提交付费视频任务。事件日志最多保留当前及上一份、每份约256 KB。

```sh
PATH="$PWD/.local/bin:$PATH" node scripts/service-watchdog.mjs status
PATH="$PWD/.local/bin:$PATH" node scripts/service-watchdog.mjs stop
PATH="$PWD/.local/bin:$PATH" node scripts/service-watchdog.mjs start
```

边界：本机休眠期间不能执行恢复；关机重启后仍需要运行Start-Local。尚未配置登录自启动或远程告警。仍存活但卡死的进程不会被自动强杀，需要人工核对任务后处理。长期故障和生产服务器守护不据本次短时验收宣称通过。
