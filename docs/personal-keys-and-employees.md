# 个人 4yi Key 与自定义员工使用说明

更新日期：2026-11-11。对应验收记录见 [本次验证](verification/2026-11-11-personal-keys-employees.md)。

## 保存自己的 Key

1. 登录后打开“设置 → 我的 4yi Key”。
2. 填写自己在 4yi 获取的 Key，点击“保存个人 Key”。保存成功后输入框清空，只显示保存状态，不回显密钥原文。
3. 点击“验证连接（不生成）”。这一步读取模型目录，不生成内容；目录通过不代表每个模型都有余额或生成权限。
4. 正式对话、员工任务和视频调用使用发起人的个人 Key。没有个人 Key 时会提示补充，不借用企业或其他人的 Key。

个人 Key 按“工作空间 + 登录用户”分别保存。服务器加密存储，浏览器不把 Key 存入本地持久缓存。同一个账号切换工作空间后，应检查该工作空间的保存状态。

### 原来的企业 Key 为什么看不到？

以前的企业 Key 没有删除，仍加密保存在原配置中。现在模型调用改为个人 Key，原企业 Key 不作为自动备用凭据。

如果你是企业所有者，而且原配置最后由你保存，在尚未配置个人 Key 时会显示“接入我以前保存的 Key”。点击后将原 Key 加密保存到你自己的个人记录，保留原企业配置。系统无法确认原保存人时，不提供导入；请从自己的 4yi 后台取得 Key 后填写。其他成员不会获得这份旧 Key。

这次本机已替原保存人完成接入并验证。无需重复导入，也无需在聊天中发送 Key。

### 更新、删除和旧任务

- 更换 Key：在个人页面填入新 Key 并保存。同一份配置在另一页面已改变时，会要求重新载入，避免覆盖。
- 删除 Key：仅移除当前工作空间中自己的个人凭据，随后新调用会被拦截。
- 视频生成记录绑定发起人及 Key 版本。换 Key 后，尚未完成的旧平台任务不会偷偷改用另一份 Key 查询；界面会提示凭据已改变。
- 历史成片保留访问能力，但只允许原任务所有者读取。使用旧共享身份创建的任务不能直接继续付费执行，需要创建新任务，避免沿用共享会话。

## 创建马上可以使用的新员工

1. 在招聘员工页面创建员工，填写姓名，选择已有角色形象、部门、岗位和能力。
2. 新员工默认待岗；保存后即可编辑，不需要改代码或更新程序版本。
3. 在技能库创建员工技能：描述需求 → 生成草稿 → 编辑 → 试运行 → 确认启用 → 绑定指定员工。试运行可在待岗状态进行。
4. 到员工档案检查该员工的独立技能；其他员工的绑定不会自动改变。
5. 有空工位时让员工上岗。之后可直接对话，或由秘书安排任务；执行会读取该员工的岗位、能力和已启用技能版本，结果进入任务记录与归档。

修改技能后应对新版本重新试运行再启用。已有运行记录保留原版本，不把旧结果误当作新版本验证。新员工可复用已有角色动画，本次没有制作或修改动画素材。

## 能力边界

员工能力描述和技能是工作指令，只有产品实际接入的工具才能执行对应操作。写上“发布到某平台”不会自动获得平台账号、接口或权限；上传一份技能文档也不会凭空安装软件。以后下载工具或技能时，需要检查格式、工具依赖和授权，并做试运行。

本次已验证新员工的文本任务、独立技能读取、版本和归档流程。个人 Key 的真实短文本调用、视频模型目录与旧成片读取已验证；没有重新付费生成一部新视频，因此不能把这些结果当作新成片质量验收。
