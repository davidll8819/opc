# 部门、岗位与员工设置

本地入口：左侧「设置 → 部门与岗位」，以及「招聘员工 → 点击角色」。

## 建立自己的团队

1. 在「设置 → 部门与岗位」点击「新建部门」，填写部门名称和职责。
2. 在这个部门里点击「新增岗位」，填写岗位名称、能力模板，最后点击「保存部门与岗位」。
3. 到「招聘员工」点击一个角色，在「岗位与能力」选择部门、岗位模板。模板会填入岗位名称与职责；你还可以继续单独修改。
4. 在「员工技能」勾选这位员工使用的已安装技能，最多 8 个。没有合适的技能，可以到技能库创建或安装。
5. 在「员工模型」单独配置这位员工的模型，或留空继承部门设置。点击「保存员工设置」。
6. 员工已经上岗时也可以编辑，不必先下岗；但系统识别到执行中的任务时会暂缓保存，提示先完成或停止任务。

新建岗位是新增可选的工作职责模板，不会凭空增加角色或占用工位。现有角色可以分配到这些岗位，办公室仍有 9 个工位。

## 模型怎么选择

优先级：**员工独立模型 → 所属部门模型 → 公司默认模型**。

- 文字、联网搜索、图片、视频可以分别填写。
- 点击「读取可用模型」使用已保存的工作空间 API Key 查询目录，不产生生成请求；输入框会列出同类候选模型。
- 原有部门留空时保留原来的模型档位、开关和备用设置；新建部门留空时使用公司默认设置。
- 清空员工单独填写的模型并保存，即恢复继承。
- 搜索候选来自文字模型目录，是否支持联网仍需该模型及中转通道实际开放。模型在列表里不等于所有工具都能使用。
- 调整模型后，旧的自检记录会标为已过期；可从「公司模型与连接」执行新自检（会产生少量调用费用）。

填写新岗位或能力不会自动开通外部账号、联网、视频制作或代码执行工具。专用工作台仍受原有工具接入和权限限制。

## 保存与保护

- 部门、岗位与员工资料按工作空间隔离；普通成员可以查看，管理员可以修改。
- 独立技能只绑定所选员工，不自动复制给部门内其他员工。
- 切换部门保留员工的独立技能、能力和模型覆盖；选择岗位模板才会填入该模板的名称和能力。
- 修改岗位模板不会覆盖已经配置好的员工。需要调整现有员工时，到员工设置重新选择模板或单独编辑。
- 有员工关联的部门或岗位不能直接删除，需先调动人员。
- 多个页面同时编辑时，旧页面会收到冲突提示，不覆盖新版本；重新载入后再修改。
- 员工设置弹窗关闭、部门设置切换导航或刷新时，有未保存内容会提示确认。

## 当前边界

本次完成的是团队配置。API Key 当前仍是工作空间级配置；**个人 4yi Key 的独立保存及视频制作链路的逐用户凭据隔离尚未实现**。不能据此认为普通成员已能够使用自己的 Key 完成整条视频制作流程。

本轮没有改动现有办公室动画，也没有自动更换任何真实员工的模型、技能、座位和岗位。
